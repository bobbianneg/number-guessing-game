
# Number Guessing Game

A simple console-based guessing game written in C++.

The player must guess a randomly generated number between 1 and 100. The game provides hints when guesses are too high or too low, tracks the number of guesses, and includes a bonus reward for winning in under 10 guesses.

## Features

- Random number generation
- Guess counter
- Too high / too low hints
- Replay system
- Easter eggs
- ASCII art reward
- Multiple ending messages

## Concepts Used

- Variables
- If / Else statements
- Do-While loops
- User input/output
- Random numbers
- Thread sleep delays
- Strings and characters

Compile:

g++ rand_gen.cpp -o game
